# V1 UDT 交易历史 RPC 正确性用例评审

评审范围：核对 `GET /api/v1/udt_transactions/:id` 的全局代币历史以及 `GET /api/v1/address_udt_transactions/:id` 的地址与代币交集历史
源码版本：`develop@0495ecd00a839f7618bad752f5ad92071124a991`

## 接口说明

- 接口作用：返回一个已发布 UDT 的已提交交易，并可按交易哈希或地址过滤；地址入口应返回给定地址参与该 UDT 的交易。
- 输入：全局入口使用 Type Hash 路径及可选 `tx_hash`、`address_hash`、`page`、`page_size`；地址入口使用地址路径、必填 `type_hash` 及分页参数。
- 成功结果：主网和测试网分别以同网络 CKB Indexer 找到候选交易，再用节点 RPC 验证提交状态、区块顺序、输入输出和 UDT Type Script；列表成员去重且预览与原始交易一致。
- 失败结果：无效哈希、地址、分页、未发布或不存在的 UDT 返回对应错误；Indexer/RPC 缺失或重组只使该网络事实基准不可用。
- 不负责：CSV、pending 交易、代币元数据可信度、普通地址详情、Omiga 生命周期及通用 HTTP/缓存契约。

## 待评审用例

| 用例 | 场景 | 预期结果 | 防止的问题 | 优先级 |
| --- | --- | --- | --- | --- |
| `UDT-TX-RPC-01` | - [x] 已发布 UDT 关联已提交、pending 和其他代币交易时按 Type Hash 请求全局历史 | 只返回该 UDT 关联的已提交交易；每个交易哈希唯一，并与同网络 Indexer 按 Type Script 找到的交易集合一致 | 混入 pending、其他代币交易或重复 join 记录 | P0 |
| `UDT-TX-RPC-02` | - [x] 全局历史省略分页参数，或显式请求相邻页面和超大页长 | 默认每页 10 条，按区块时间降序且同区块按交易索引降序；相邻页是稳定全量顺序的连续切片，meta 总数一致，页长最多 100 | 默认顺序漂移、翻页漏项重项或无界查询 | P1 |
| `UDT-TX-RPC-03` | - [x] 全局历史的 `page`、`page_size` 为零、负数或非整数 | 返回对应分页参数错误；两个参数同时无效时同时报告两项，不查询历史 | 畸形分页触发服务异常或错误页面 | P1 |
| `UDT-TX-RPC-04` | - [x] 提供属于目标 UDT 的合法 `tx_hash`，以及不属于目标 UDT的合法哈希 | 前者只返回该笔交易，后者返回空数组且 meta 总数为 0，不跨 UDT 命中 | 交易哈希过滤被忽略或串到其他代币 | P1 |
| `UDT-TX-RPC-05` | - [x] 提供参与目标 UDT 交易的 CKB 地址或可映射到多个地址的查询值 | 返回目标 UDT 交易与解析后地址集合的交集，多个 account-book 命中仍按交易去重 | 地址过滤只匹配一个映射地址或 join 产生重复 | P0 |
| `UDT-TX-RPC-06` | - [x] 对全局历史中的普通交易和 Cellbase 边界样本核对序列化结果 | `transaction_hash`、区块高度和时间、Cellbase 标识、输入输出数量与前 10 项预览、创建毫秒值和可选 RGB/Bitcoin 标志结构完整；链相关字段与同一 RPC 交易及引用输出一致 | 交易摘要拼错、输入输出预览错序或跨交易串值 | P0 |
| `UDT-TX-RPC-07` | - [x] 已发布 UDT 没有关联交易，或请求超出最后一页 | 返回空 `data`，meta 保留过滤后总数、页长和总页数，不把空历史当成错误 | 空页返回残留数据或丢失分页上下文 | P2 |
| `UDT-TX-RPC-08` | - [x] 全局入口的 Type Hash 或可选 `tx_hash` 格式错误，地址无法解析，UDT 不存在或未发布 | 分别返回 Type Hash、交易哈希、地址或 UDT not-found 错误；不返回部分交易数据 | 无效过滤触发 500、回退为未过滤查询或泄露未发布记录 | P1 |
| `UDT-TX-RPC-09` | - [ ] 地址入口使用合法地址和已发布 UDT Type Hash，且链上同时有该地址参与和未参与的目标 UDT 交易 | 待确认：结果应为地址参与集合与目标 UDT 集合的交集；当前 `Address#ckb_udt_transactions` 仅返回 UDT 全局关系，需确认并修正产品语义后再自动化 | 地址专属接口返回全体 UDT 交易，泄露无关活动 | P0 |
| `UDT-TX-RPC-10` | - [x] 地址入口省略分页参数或显式翻页 | 默认每页 10 条，按区块时间和交易索引降序，meta 总数只统计确认后的地址与 UDT 交集，页长最多 100 | 地址历史分页基于错误的全局集合或总数 | P1 |
| `UDT-TX-RPC-11` | - [x] 地址入口返回命中交易时核对预览字段 | 返回与全局入口一致的交易摘要和输入输出预览，且 `income` 对应该查询地址在交易中的 CKB 容量净变化；UDT 成员身份由 Type Script 证明 | 地址上下文丢失、income 使用其他地址或预览与全局入口不一致 | P0 |
| `UDT-TX-RPC-12` | - [x] 地址格式错误、`type_hash` 缺失或格式错误、地址不存在、UDT 不存在或未发布、分页无效 | 按验证顺序返回地址、Type Hash、address-not-found、UDT not-found 或分页错误，不执行未过滤历史查询 | 错误参数被忽略并返回全局交易 | P1 |
| `UDT-TX-RPC-13` | - [x] 同网络 Indexer/RPC 缺少交易、输入引用结果不可用或观测期间发生重组 | 该网络依赖成员和字段的结论标记为事实基准不可用，不判为 API 数据错误；另一网络独立执行 | 索引延迟、RPC 局部故障或重组制造误报 | P1 |

## 本轮需要确认
