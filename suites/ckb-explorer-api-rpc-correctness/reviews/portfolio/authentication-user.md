# Portfolio 身份与用户设置正确性用例评审

评审范围：核对 Portfolio 签名登录、JWT 鉴权以及 PATCH/PUT 用户名称更新的身份绑定、隔离和状态保持
源码版本：`develop@0495ecd00a839f7618bad752f5ad92071124a991`

## 接口说明

- 接口作用：用 CKB 地址签名证明创建或复用 Portfolio 用户并签发 JWT，再用 JWT 更新当前用户名称。
- 输入：`POST /api/v2/portfolio/sessions` 的 `address`、`message`、`signature`、可选 `pub_key`，以及 `PATCH /api/v2/portfolio/user`、`PUT /api/v2/portfolio/user` 的 Authorization JWT 和 `name`。
- 成功结果：签名与当前网络地址匹配时返回当前用户名称和有限有效期 JWT；有效 JWT 的 PATCH/PUT 只更新对应用户并返回 204。
- 失败结果：无效签名、错误网络地址、无效或过期 JWT、JWT 对应用户不存在及无效名称返回领域错误，且不创建或修改用户状态。
- 不负责：Portfolio 地址、资产和交易数据，JWT/错误对象的跨版本兼容性，以及通用 HTTP 媒体类型契约。
