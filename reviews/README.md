# 测试领域与评审文档

目标源码：`https://github.com/nervosnetwork/ckb-explorer.git`，当前分析版本 `develop@0495ecd00a839f7618bad752f5ad92071124a991`。
执行方式：兼容性套件比较基准与候选环境的 HTTP 行为；RPC 正确性套件把 Explorer API 结果与同一网络、同一区块高度的 CKB RPC 结果或可验证推导值比较。机器可执行的路由与 fixture 保存在各套件配置中，不在评审文档重复维护。

| 测试领域 | 责任与边界 | 入口 | 可观察结果 | 评审文档 |
| --- | --- | --- | --- | --- |
| HTTP API 通用契约 | 比较所有接口共有的路由、媒体类型、错误、分页、CSV、缓存和差异报告规则；不判断具体业务数据是否正确 | `/api/v1/*`、`/api/v2/*`、基准与候选 URL | 状态、选定响应头、数据类型和值、顺序、分页、逐字段差异 | `suites/ckb-explorer-api-rpc-compatibility/reviews/http-api-contract.md` |
| V1 区块列表 RPC 正确性 | 在公开主网和测试网分别以 Explorer 返回的区块高度为锚点，与同网络 CKB RPC 核对区块身份及可直接验证的列表字段，并单独观测同步高度差；不跨网络比较，也不评审双 Explorer 环境兼容性、通用 HTTP 契约、分页和排序 | 主网与测试网的 `GET /api/v1/blocks`、`GET /api/v1/blocks/:height`，以及同网络 CKB RPC `get_tip_header`、`get_block_by_number` 与 `get_block_economic_state` | 每个网络内的 API/RPC 链身份、同步高度差、区块高度、哈希、时间戳、交易数量，以及派生字段的计算证据与差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-blocks-index.md` |
| V1 区块详情 RPC 正确性 | 在公开主网和测试网分别按区块高度与区块哈希查询同一规范链区块，并用同网络 CKB RPC 及可验证推导值核对详情字段；不跨网络比较，也不评审双 Explorer 环境兼容性、通用 HTTP 契约和区块交易列表 | 主网与测试网的 `GET /api/v1/blocks/:id`，以及同网络 CKB RPC `get_block_by_number`、`get_block`、`get_block_economic_state` 与必要的链参数查询 | 高度与哈希两种查询的一致性、区块头与 Epoch 字段、交易/提案/叔块计数及根哈希、容量/费用/奖励、矿工信息、区块大小与 cycles 等可核对详情值及差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-blocks-show.md` |
| V1 区块 CSV RPC 正确性 | 在公开主网和测试网分别下载区块 CSV，并用同网络 CKB RPC 核对默认及过滤后的区块集合、顺序、500 行上限和可由链数据推导的列值；不跨网络比较，也不评审双 Explorer 环境兼容性、通用下载响应头、错误契约和 CSV 转义规范 | 主网与测试网的 `GET /api/v1/blocks/download_csv` 及其 `start_date`、`end_date`、`start_number`、`end_number` 过滤条件，以及同网络 CKB RPC `get_block_by_number`、`get_block_economic_state` | CSV 表头和列映射、筛选边界、区块高度顺序与行数上限、交易数量、Unix 时间戳、CKB 奖励、矿工地址和 UTC 日期及差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-blocks-download-csv.md` |
| V1 区块交易列表 RPC 正确性 | 在公开主网和测试网分别以规范链区块哈希查询 Explorer 交易列表，并用同网络 CKB RPC 核对交易归属、顺序和可由链数据推导的摘要字段；不跨网络比较，也不评审双 Explorer 环境兼容性、通用 HTTP 契约、分页规则、创建时间以及 RGB/Bitcoin 索引注解 | 主网与测试网的 `GET /api/v1/block_transactions/:block_hash` 及其 `tx_hash`、`address_hash` 过滤条件，以及同网络 CKB RPC `get_block`、`get_transaction` | 区块内交易集合与链上顺序、交易哈希、Cellbase 标识、区块高度与时间戳、输入输出计数和预览，以及按交易哈希或链上地址过滤后的成员关系及差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-block-transactions-show.md` |
| V1 交易列表 RPC 正确性 | 在公开主网和测试网分别取得近期已提交的普通交易简表，并用同网络 CKB RPC 核对默认列表成员、时间与区块内顺序以及五个可由链数据推导的字段；不跨网络比较，也不评审双 Explorer 环境兼容性、通用 HTTP 契约、显式分页和排序、交易详情、条件查询、待处理交易及协议扩展注解 | 主网与测试网不带 `page`、`page_size` 的 `GET /api/v1/transactions`，以及同网络 CKB RPC `get_tip_header`、`get_block_by_number`、`get_block`、`get_transaction` 和输入引用的上一笔交易 | 最新普通已提交交易的集合与顺序、交易哈希、区块高度与时间戳、输入容量总和、输入输出数量差及逐字段差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-transactions-index.md` |
| V1 交易详情 RPC 正确性 | 在公开主网和测试网分别按已提交普通交易及 Cellbase 交易哈希查询详情，并用同网络 CKB RPC 核对交易原始结构、区块归属和可由链数据推导的详情字段；覆盖是否展示 Cells 的调用方开关，不跨网络比较，也不评审双 Explorer 环境兼容性、通用 HTTP 与错误契约、待处理或拒绝状态、全局与 Epoch 极值以及 RGB/Bitcoin/UDT/DAO 等协议扩展注解 | 主网与测试网的 `GET /api/v1/transactions/:id` 及可选 `display_cells`，以及同网络 CKB RPC `get_transaction`、`get_block` 和输入引用的上一笔交易 | 交易哈希与提交状态、普通交易与 Cellbase 标识、版本、witnesses、Cell/Header Dependencies、区块高度与时间戳、输入输出成员和顺序、容量与脚本等可推导展示值、交易费、序列化大小、cycles、Cells 展示开关及逐字段差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-transactions-show.md` |
| V1 交易条件查询 RPC 正确性 | 在公开主网和测试网分别按 CKB 地址查询已提交交易，并用同网络 CKB Indexer 与节点 RPC 核对过滤成员、链上顺序及列表详情；同时核对省略地址时的全局查询分支，不跨网络比较，也不评审双 Explorer 环境兼容性、通用 HTTP 与分页错误契约、数据库创建时间及 RGB/Bitcoin/UDT/DAO 等协议扩展注解 | 主网与测试网的 `POST /api/v1/transactions/query`，JSON 参数 `address`、`page`、`page_size`，以及同网络 CKB Indexer `get_transactions` 和节点 RPC `get_transaction`、`get_block`、输入引用的上一笔交易 | 地址参与交易的去重集合与顺序、分页成员及总数、交易哈希和区块字段、输入输出总数与前 10 项预览、查询地址净容量变化 `income`、省略地址时的最近普通交易及逐字段差异 | `suites/ckb-explorer-api-rpc-correctness/reviews/chain-data/v1-transactions-query.md` |
